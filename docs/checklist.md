## 阶段〇：项目初始化与环境配置

### 〇.1 项目脚手架

- [ ] Next.js 项目已创建（已完成）
- [ ] TypeScript 配置正确（已完成）
- [ ] Tailwind CSS v4 配置正确（已完成）
- [ ] ESLint 配置正确（已完成）
- [ ] 目录结构规划完成

### 〇.2 目录结构

```
src/
├── app/                    # App Router 页面
│   ├── layout.tsx          # 根布局
│   ├── page.tsx            # 首页
│   ├── customize/          # 定制工具
│   ├── shop/               # 商城
│   ├── encyclopedia/       # 百科
│   └── about/              # 关于
├── components/             # 共享组件
│   ├── ui/                 # 基础 UI 组件 (Button, Card, Badge...)
│   ├── layout/             # 布局组件 (Navigation, Footer...)
│   ├── home/               # 首页专属组件
│   └── shop/               # 商城专属组件
├── lib/                    # 工具函数与配置
│   ├── utils.ts            # 通用工具
│   ├── constants.ts        # 常量/静态数据
│   └── theme.ts            # 主题逻辑
├── hooks/                  # 自定义 Hooks
├── types/                  # TypeScript 类型定义
└── public/                 # 静态资源
    ├── images/
    └── fonts/              # (如果自托管字体)
```

### 〇.3 依赖安装

- [ ] Framer Motion（动画库）
- [ ] next-themes（主题切换，或自实现）
- [ ] 字体：Noto Serif SC, Noto Sans SC, Cormorant Garamond, Inter
- [ ] 其他需要的依赖

**验收标准**：`npm run dev` 正常启动，访问 `localhost:3000` 看到页面。

## 阶段一：设计系统落地

### 1.1 CSS 变量与主题系统

- [ ] 定义深色主题（般若 · Prajna）CSS 变量
- [ ] 定义浅色主题（素简 · Shuddha）CSS 变量
- [ ] 实现主题切换逻辑（localStorage + 系统偏好检测)
- [ ] 主题切换过渡动画（500ms ease-out）
- [ ] 防止页面闪烁的内联脚本

### 1.2 全局样式

- [ ] 全局 CSS Reset / 基础样式
- [ ] 排版层级样式（h1-h6, body, small, caption）
- [ ] 间距系统（space-1 ~ space-24）
- [ ] 圆角系统（radius-sm ~ radius-full）
- [ ] 自定义缓动函数（ease-default, ease-out, ease-spring 等）

### 1.3 基础 UI 组件

- [ ] **Button**：主按钮（金色填充）、次按钮、幽灵按钮，含 loading、disabled 状态
- [ ] **Card**：基础卡片容器，含 hover 金色边框发光效果
- [ ] **Badge**：角标/标签组件
- [ ] **SectionTitle**：区块标题（含装饰线/装饰元素）
- [ ] **ScrollReveal**：滚动触发出场动画封装
- [ ] **StaggerGrid**：交错网格动画封装
- [ ] **LoadingSkeleton**：骨架屏组件

**验收标准**：Storybook 或独立页面中展示所有组件及其状态变体。
