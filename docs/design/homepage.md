# 首页设计文档

## 1. 概述

### 1.1 页面目的

首页是整个念珠定制网站的**第一印象**和**核心流量入口**。它需要在数秒内完成以下任务：

1. **传递品牌精神** — 让访客感受到念珠文化的宁静与庄严
2. **引导定制入口** — 清晰地将用户引向定制流程
3. **展示精选商品** — 罗列代表性念珠，激发购买欲
4. **建立信任** — 通过材质工艺展示和品牌故事建立品质信任
5. **降低门槛** — 让不了解念珠的用户也能轻松理解产品价值

|------|-----|

#### 3.2.4 粒子背景规范

详见 [交互动效文档](interaction-design.md#1-粒子背景-particle-system)，核心参数：

| 参数 | 值 |
|------|----|
| 粒子数 | 30 ~ 50 |
| 粒子大小 | 2px ~ 4px |
| 颜色 | `var(--color-accent)` 带 alpha |
| 透明度范围 | 0.08 ~ 0.25 |
| 浮动速度 | 8s ~ 12s 一个完整周期 |
| 鼠标跟随 | 偏移量 ≤ 15px, 300ms 延迟响应 |
| 性能降级 | 移动端粒子数减半 (15 ~ 25)，禁用鼠标跟随 |

#### 3.2.5 向下滚动指示器

位置: Hero 底部，水平居中，距离底部 48px

```
       ↓        ← 箭头图标: 24px × 24px
    scroll      文字: text-xs, --color-text-muted
```

- 动画: 透明度 0.4 ↔ 1.0 呼吸，周期 2s
- 点击: 平滑滚动到下一个区块 (`scrollIntoView({ behavior: 'smooth' })`)
- 首屏外隐藏: 滚动超过 Hero 后渐出 (opacity → 0, 300ms)

#### 3.2.6 响应式行为

| 断点 | 布局变化 |

| 移动端 (< 640px) | 品牌图标 48px，Slogan text-3xl，CTA 改用全宽堆叠排列，间距 gap-3 |
| 平板 (640~1024px) | 标准布局，Slogan text-5xl |
| 桌面 (> 1024px) | 完整 Hero，Slogan text-7xl，粒子 50 个 |
