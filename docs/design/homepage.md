# 首页设计文档

## 1. 设计理念

### 1.1 核心气质

**静 · 空 · 寂 · 简 · 质 · 慢**

| 维度 | 标准 | 落地方式 |
|------|------|----------|
| **静** | 没有不必要的动效 | 无粒子背景、无旋转光效、无水波纹，极静态 Hero |
| **空** | 留白足够 | 区块间距 `py-32`，区块标题使用单字 + 点号装饰 |
| **寂** | 色彩极度克制 | 金色仅用于 Logo 和 CTA hover，其余均为低对比辅助色 |
| **简** | 元素能减尽减 | 导航栏仅 3 项，无 CTA 按钮，无主题切换器 |
| **质** | 真实材质感 | 深色背景使用微噪声叠加，浅色背景模拟宣纸暖白 |
| **慢** | 交互节奏从容 | 过渡动画统一 `500ms ease-out`，无急骤变化 |

### 1.2 页面目的

首页是念珠品牌的**精神入口**，而非销售漏斗。它在数秒内需完成：

1. **传递禅意** — 让访客感受到宁静与庄严的氛围
2. **引导探索** — 自然地吸引用户向下浏览，而非强推转化
3. **建立信任** — 通过材质工艺与品牌故事传递品质感
4. **提供入口** — 温和地引导有意者进入定制或商城

### 2.2 滚动行为

| 行为 | 说明 |
|------|------|
| 滚动容器 | 页面级滚动，无内部滚动区域 |
| 滚动捕捉 | 不启用 — 自然滚动更符合禅意 |
| 平滑滚动 | 全局 `scroll-behavior: smooth` |
| 进度指示 | 不设 — 用户不需要被提醒进度 |
| 过渡时间 | 所有交互相应 `500ms ease-out` |

## 3. 区块详细设计

### 3.1 导航栏 (Navigation)

#### 3.1.1 核心原则

**极简。** 导航栏不是转化工具，是氛围的一部分。

#### 3.1.2 布局

```
┌───────────────────────────────────────────────┐
│  NIAN·ZHU             商城 · 百科 · 关于       │
│                                                │
└───────────────────────────────────────────────┘
```

| 元素 | 位置 | 规格 |
|------|------|------|
| 品牌名 | 左侧 | `NIAN·ZHU`，`font-serif`，`text-sm tracking-[0.15em] uppercase` |
| 导航链接 | 右侧 | 3项，`font-[300]`，`text-xs tracking-[0.1em] uppercase` |
| 链接分隔 | 链接间 | `·` 点号，`--color-text-muted` |
| CTA 按钮 | 不设 | Hero 区才是转化主战场 |
| 主题切换 | 不设 | 跟随系统主题 |

### 3.2 Hero 区域

#### 3.2.1 核心原则

**静默。** 没有任何动态元素喧宾夺主。品牌信息本身就是唯一的主角。

#### 3.2.2 布局

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│                                                         │
│                                                         │
│                     NIAN·ZHU                             │  font-serif, text-xs, tracking-[0.2em]
│                                                         │
│                  一念清净 一串菩提                        │  font-serif, text-5xl md:text-7xl, leading-tight
│                                                         │
│                Every Bead a Meditation                   │  font-serif italic, text-lg, --color-text-secondary
│                                                         │
│                                                         │
│                   [ 启程 ]  [ 观览 ]                     │  gap-6, mt-16
│                                                         │
│                                                         │
│                        ↓                                │  滚动指示器, 底部 48px
│                                                         │
└─────────────────────────────────────────────────────────┘
```

| 属性 | 值 |
|------|----|
| 高度 | `min-h-screen` |
| 背景 | `linear-gradient(180deg, #0C0C0A 0%, #1A1610 100%)` |
| 光晕 | 一个固定的径向渐变 `radial-gradient(circle at 50% 40%, rgba(255,185,0,0.05) 0%, transparent 60%)` — 非动画 |
| 内容对齐 | `flex flex-col items-center justify-center text-center` |
| 无粒子 | 不设 Particle Canvas 或任何动态背景 |

#### 3.2.3 内容规格

| 元素 | 规格 |
|------|------|
| 英文品牌 | `NIAN·ZHU`，`font-serif`，`text-xs tracking-[0.2em] uppercase`，`--color-text-muted`，`mb-6` |
| 主 Slogan | `一念清净 一串菩提`，`font-serif`，`text-5xl md:text-7xl`，`leading-tight`，`tracking-wide` |
| 英文副标 | `Every Bead a Meditation`，`font-serif italic`，`text-lg md:text-xl`，`--color-text-secondary`，`mt-4` |
| 中英文间距 | `gap-4`，英文副标有足够呼吸感 |

#### 3.2.4 CTA 按钮

**主按钮"启程"**：
| 属性 | 值 |
|------|----|
| 样式 | 幽灵按钮 `bg-transparent border border-[var(--color-accent)]` |
| 文字色 | `--color-accent` |
| 尺寸 | `px-8 py-3 text-sm tracking-[0.1em] uppercase` |
| 圆角 | `radius-md` |
| 悬停 | `bg-[var(--color-accent)] text-[var(--color-bg-primary)]` |
| 点击跳转 | `/customize` |

**副按钮"观览"**：
| 属性 | 值 |
|------|----|
| 样式 | 幽灵按钮 `bg-transparent border border-[var(--color-border)]` |
| 文字色 | `--color-text-secondary` |
| 尺寸 | `px-8 py-3 text-sm tracking-[0.1em] uppercase` |
| 圆角 | `radius-md` |
| 悬停 | `border-[var(--color-accent)] text-[var(--color-accent)]` |
| 点击跳转 | `/shop` |

两个按钮风格统一，主次通过悬停行为区分，而非填充色抢眼。

**移除**：
- ❌ 水波涟漪点击反馈
- ❌ `scale(0.97)` 缩放
- ❌ 金色填充按钮

#### 3.2.5 向下滚动指示器

```
       ↓         箭头图标, 16px, opacity-40
```

- `position: absolute; bottom: 48px; left: 50%; transform: translateX(-50%)`
- 透明度呼吸: `opacity-30` ↔ `opacity-70`，周期 `3s ease-in-out`
- 点击: 平滑滚动到下一区块
- 滚动超过 Hero 后渐出

#### 3.2.6 响应式

| 断点 | 变化 |
|------|------|
| 移动端 (< 640px) | Slogan `text-3xl`，英文副标 `text-base`，按钮全宽堆叠 |
| 平板 (640-1024px) | Slogan `text-5xl` |
| 桌面 (> 1024px) | 完整 Hero |

### 3.3 择 · 合 · 成（原"定制流程"）

#### 3.3.1 核心原则

**不是"三步流程"，而是"三种心境"。** 去掉编号、去掉箭头连接线、去掉进度感。

#### 3.3.2 布局

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│                     · 择 ·                              │  区块标题
│                                                         │
│                                                         │
│      择                     合                     成    │  单字标题
│      —                      —                     —     │  装饰分隔线
│  从天然木材、水晶、       隔珠、流苏、坠饰       3D 预览成品      │
│  玛瑙中挑选珠材          自由搭配               匠人手工制作     │
│                                                         │
│  (无编号)              (无编号)               (无编号)    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

| 属性 | 值 |
|------|----|
| 间距 | `py-32` |
| 布局 | 桌面三列 `grid-cols-1 md:grid-cols-3`，`gap-16` |
| 背景 | `--color-bg-primary` |

#### 3.3.3 区块标题

| 元素 | 规格 |
|------|------|
| 标题 | `· 择 ·`，`font-serif`，`text-2xl tracking-[0.15em]`，`--color-text-muted`，居中 |
| 装饰 | 标题上下各一条水平线 `w-8 h-px bg-[var(--color-border)] mx-auto my-4` |

区块标题不解释含义，三个步骤本身说明一切。

#### 3.3.4 步骤卡片

| 元素 | 规格 |
|------|------|
| 单字标题 | `择 / 合 / 成`，`font-serif`，`text-4xl`，`--color-text-primary` |
| 装饰线 | `—`，`text-sm`，`--color-text-muted`，`mt-3 mb-4` |
| 描述 | `font-[300]`，`text-sm leading-relaxed`，`--color-text-secondary` |
| 行数 | 不超过 3 行 |
| 卡片背景 | 无背景 |
| 悬停 | 无背景变化，仅文字颜色微增亮度 |

**不设**：
- ❌ 步骤编号 `01 02 03`
- ❌ 图标容器 `80px rounded-full`
- ❌ SVG 图标
- ❌ 卡片背景填充
- ❌ 步骤间连接线
- ❌ "开始定制→" 按钮

## 5. 设计原则检查清单

- [ ] **无粒子背景** — Hero 不使用任何动态粒子或 Canvas
- [ ] **无金色泛滥** — 金色仅用于 Logo 和 CTA 悬停
- [ ] **无编号** — 步骤不设 01/02/03
- [ ] **无图标容器** — 步骤卡片无圆形图标区
- [ ] **无价格标签** — 产品卡片不显示价格
- [ ] **无购物车按钮** — 产品卡片无购买入口
- [ ] **无水波纹** — 按钮点击无涟漪效果
- [ ] **无缩放反馈** — 按钮点击无 scale 变化
- [ ] **无滚动进度条** — 右侧无进度指示
- [ ] **无滚动捕捉** — 不启用 scroll-snap
- [ ] **无主题切换器** — 跟随系统主题
- [ ] **无社交媒体图标** — Footer 不设社交链接
- [ ] **无创始人照片** — 品牌故事不放人像
- [ ] **过渡统一 500ms** — 所有交互相应
- [ ] **留白充足** — 区块间距 py-32
