# 页面结构

## 整体导航结构

```
┌─────────────────────────────────────┐
│              Navigation              │  ← 磨砂玻璃效果，随滚动透明度变化
├─────────────────────────────────────┤
│                                      │
│           Hero / Banner              │  ← 全屏沉浸式入口，动态背景
│                                      │
├─────────────────────────────────────┤
│                                      │
│        定制流程展示 (3 Steps)         │  ← 水平滚动/交错出现
│                                      │
├─────────────────────────────────────┤
│                                      │
│        精选念珠 (Featured)           │  ← 卡片网格，2行
│                                      │
├─────────────────────────────────────┤
│                                      │
│        材质与工艺展示                │  ← 视觉化展示核心卖点
│                                      │
├─────────────────────────────────────┤
│                                      │
│        用户体验背书 / 寄语            │  ← 禅意文案 + 氛围图
│                                      │
├─────────────────────────────────────┤
│                                      │
│              Footer                  │
└─────────────────────────────────────┘
```

---

## 页面区块详解

### 1. 导航栏 (Navigation)

| 元素 | 说明 |
|------|------|
| **Logo** | 品牌名 + 简约图标（莲花/法轮/念珠图形） |
| **链接** | 首页 · 定制 · 商城 · 百科 · 关于 |
| **CTA** | "开始定制" 按钮（金色边框幽灵按钮） |
| **购物车** | 图标 + 数量角标 |
| **效果** | 初始透明，滚动后磨砂玻璃背景 (`backdrop-filter: blur`) |

---

### 2. Hero 区域

**布局**: 全屏，内容居中

```
┌─────────────────────────────────────────┐
│                                         │
│            动态粒子背景                   │  ← Canvas / CSS 粒子动画
│                                         │
│      ┌─────────────────────┐            │
│      │    Logo / 品牌标识   │            │
│      │                     │            │
│      │  一念清净 · 一串菩提  │            │  ← 中英文 Slogan
│      │                     │            │
│      │  [开始定制] [浏览成品] │            │  ← 双按钮入口
│      └─────────────────────┘            │
│                                         │
│          ↓ 滚动提示 (淡入淡出)            │
│                                         │
└─────────────────────────────────────────┘
```

**关键元素**:
- **动态粒子背景**: 漂浮的微光粒子，缓慢运动，模拟香炉烟雾或星空
- **Slogan**: "一念清净 · 一串菩提" + 英文副标题
- **双 CTA**: 主按钮"开始定制"（金色填充），副按钮"浏览成品"（幽灵按钮）
- **滚动提示**: 底部中央的向下箭头，带呼吸动画

---

### 3. 定制流程展示 (How It Works)

三步骤水平排列，随滚动逐个淡入并上移。

| 步骤 | 图标 | 标题 | 描述 |
|------|------|------|------|
| 01 | 选择珠子 | 选材 | 从天然木材、水晶、玛瑙中挑选 |
| 02 | 搭配配饰 | 搭配 | 隔珠、计数器、流苏、坠饰自由组合 |
| 03 | 完成定制 | 圆满 | 预览成品，下单即开始手工制作 |

**动效**: 每个步骤卡片在进入视口时从左/右/下方向交错入场，带轻微弹性效果。

---

### 4. 精选念珠 (Featured Products)

**布局**: 2列 x 4行 网格（桌面），移动端单列

```
┌─────────────────────┐  ┌─────────────────────┐
│  ┌───────────────┐  │  │  ┌───────────────┐  │
│  │  产品图片      │  │  │  │  产品图片      │  │
│  │  (hover 放大)  │  │  │  │  (hover 放大)  │  │
│  └───────────────┘  │  │  └───────────────┘  │
│  六道木手持念珠     │  │  紫檀木佛珠          │
│  ￥168              │  │  ￥298              │
│  [查看详情]         │  │  [查看详情]         │
└─────────────────────┘  └─────────────────────┘
```

**交互**:
- 鼠标悬停：图片轻微放大 (scale 1.05)，金色边框发光
- 点击卡片进入商品详情页
- 价格下方显示"已定制 N 次" 社交证明
- 懒加载 + 渐入动画

---

### 5. 材质与工艺展示

左右交替排列的图文区块，展示核心卖点。

| 区块 | 图片 | 文案 |
|------|------|------|
| 天然材质 | 木材/水晶微距特写 | "来自大自然的馈赠" |
| 手工工艺 | 工匠制作过程 | "每一颗都由匠人亲手打磨" |
| 文化传承 | 传统念珠美感 | "千年传承的修行之器" |

**布局**: 图片与文字左右对调排列（ABAB 模式），营造节奏感。

```
[图片]  |  文案区块      ← 区块 A
        |
 文案区块  |  [图片]      ← 区块 B
        |
[图片]  |  文案区块      ← 区块 A
```

---

### 6. 用户寄语 / 品牌故事

**布局**: 居中横幅，背景为深色+极淡纹理

- 一段富有哲理的文字（如关于"一串念珠的意义"）
- 背景装饰：极淡的曼陀罗图案或经文光影
- CTA："开始你的定制之旅"

---

### 7. Footer

| 列 | 内容 |
|----|------|
| 品牌 | Logo + 简短品牌介绍 |
| 导航 | 首页 · 定制 · 商城 · 百科 · 关于 |
| 支持 | 配送说明 · 退换政策 · 保养指南 · 联系我们 |
| 关注 | 微信公众号 · 小红书 · Instagram |

底部版权信息 + 备案号

## 响应式断点

| 断点 | 宽度 | 布局变化 |
|------|------|----------|
| Mobile | < 640px | 单列，底部导航，精简 Hero |
| Tablet | 640px ~ 1024px | 双列网格，侧边栏导航 |
| Desktop | > 1024px | 完整多列布局，顶部导航 |
| Wide | > 1440px | 内容最大宽度 1280px，居中 |
