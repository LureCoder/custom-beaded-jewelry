# 图片素材需求

> 本文档列出网站开发所需的全部图片素材及其规格要求。

---

## 1. 需要图片的位置

| 页面 | 区块 | 用途 | 最低数量 |
|------|------|------|----------|
| 首页 | · 观 · | 精选念珠展示卡片 | 4 张 |
| 首页 | · 质 · | 材质微距特写 | 2 张 |
| 商城 | 列表页 | 每款产品封面图 | 每款 1 张 |
| 商品详情 | 详情页 | 多角度产品展示 | 每款 3-5 张 |

---

## 2. 产品主图规范（最重要）

### 2.1 核心要求

| 要求 | 规格 |
|------|------|
| 背景 | 纯黑或深灰背景 |
| 照明 | 单一侧光源，制造阴影层次，突出珠体光泽 |
| 拍摄角度 | 45 度俯拍 |
| 构图 | 展示完整的 108 珠排列或手持局部 |
| 图片比例 | **4:5 竖图** — 所有列表页统一使用 |
| 最小分辨率 | 1200 × 1500 px |
| 推荐分辨率 | 2400 × 3000 px（适配 Retina 屏幕） |
| 文件格式 | WebP（优先）或 JPEG |
| 文件大小 | 200KB - 800KB（WebP 压缩后） |

### 2.2 构图示意

```
┌──────────┐       ┌──────────┐       ┌──────────┐
│          │       │          │       │          │
│   ●●●    │       │   ～～   │       │  ▓▓▓▓   │
│  ●●●●●   │       │  ～～～～  │       │ ▓▓▓▓▓▓  │
│   ●●●    │       │   ～～   │       │  ▓▓▓▓   │
│          │       │          │       │          │
│ 菩提108   │       │ 紫檀微距  │       │ 水晶特写  │
└──────────┘       └──────────┘       └──────────┘
  45° 俯拍全貌       侧面展示厚度       微距3倍放大
```

---

## 3. 每款产品必拍清单

| # | 角度 | 用途 | 说明 |
|---|------|------|------|
| 1 | **45° 俯拍全貌** | 列表页封面 + 详情页主图 | 念珠盘放在平面上，展示完整环形 |
| 2 | **侧面** | 详情页副图 | 展示珠串厚度、佛头侧面轮廓 |
| 3 | **微距特写** | 详情页细节图 | 3-5 倍放大，展示材质纹理、菩提眼、水晶冰裂 |
| 4 | **手持场景** | 详情页氛围图 | 人手盘握的画面，自然光 |
| 5 | **静物氛围** | 详情页 / 品牌故事 | 置于经文、莲花、木质佛台上拍摄 |

> **最低门槛**：必须提供 #1（俯拍全貌）+ #3（微距特写），这是详情页必需的。

---

## 4. 材质微距特写（首页 · 质 · 区块）

| 材质 | 特写重点 | 建议放大倍率 | 图片比例 |
|------|----------|-------------|----------|
| 紫檀 | 木材纹理、油润感 | 3-5x | 1:1 方形 |
| 白水晶 | 天然冰裂、通透感 | 3-5x | 1:1 方形 |
| 凤眼菩提 | 菩提眼的形状与深度 | 4-6x | 1:1 方形 |
| 星月菩提 | 表面的星点分布 | 4-6x | 1:1 方形 |

---

## 5. 后期调色

所有产品图片统一按此参数处理：

| 参数 | 调整 | 效果 |
|------|------|------|
| 色温 | +5 | 偏暖，呼应琥珀光品牌色 |
| 对比度 | +10 | 增强珠体质感 |
| 清晰度 | +15 | 突出木材/水晶纹理 |
| 饱和度 | -5 | 沉稳内敛，不艳丽 |
| 暗角 | 轻微 | 聚焦画面中心 |
