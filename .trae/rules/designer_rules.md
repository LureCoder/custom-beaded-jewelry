# Designer 规则 · 念珠预览布局

> 本规则文件定义念珠预览组件的布局约束，所有修改必须遵守。

---

## 珠子布局约束

### 1. 所有珠子必须在框架线上

- 主珠、顶珠、腰珠必须位于框架线上
- 框架线可以是正圆、椭圆、水滴形或其他形状
- 在佛头、顶珠、腰珠等大尺寸珠子位置，框架线可以局部外扩以避免重叠
- 佛头必须位于框架线底部，连接首尾主珠
- 弟子珠、计数器、卡子必须位于对应的连接线上
- 禁止珠子脱离框架线随意摆放

### 2. 框架线形状选择

根据珠子尺寸和布局需求选择合适的框架线形状：

| 形状 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| 正圆 | 珠子尺寸相近 | 计算简单，视觉对称 | 大尺寸珠子易重叠 |
| 椭圆 | 顶部或底部有大珠子 | 可在特定方向扩展 | 需要调整纵横比 |
| 水滴形 | 佛头位置需要外扩 | 自然过渡，美观 | 计算较复杂 |
| 分段圆弧 | 不同区域不同曲率 | 灵活控制各区域 | 需要平滑连接 |

### 3. 所有珠子不能重叠（保持 1pt ≈ 1.4px 最小间距）

- 任意两颗珠子的中心距必须大于两珠半径之和 + 1.4px
- 主珠之间：中心距 ≥ 主珠直径 + 1.4px ≈ 16.4px
- 主珠与腰珠：中心距 ≥ (主珠半径 + 腰珠半径) + 1.4px ≈ 17.4px
- 主珠与顶珠：中心距 ≥ (主珠半径 + 顶珠半径) + 1.4px ≈ 18.4px
- 佛头与相邻主珠：中心距 ≥ (佛头半径 + 主珠半径) + 1.4px ≈ 18.4px
- 当前布局（R=350px, 112等分）下相邻珠中心距 ≈ 19.64px，满足所有约束

### 4. 为特殊珠子留空间时不能影响相邻珠子

- 为佛头留空间时，可以通过以下方式避免重叠：
  - 调整框架线形状（推荐）
  - 偏移相邻主珠（需验证不与更远的主珠重叠）
  - 增大环形半径
- 偏移量必须小于相邻两颗主珠的中心距减去主珠直径

### 5. 27颗主珠分段结构（核心约束）

108颗主珠分为**4段**，每段**27颗**，位于112等分环形上（含三通位置），这是念珠的核心结构，任何修改都不得违反：

| 分段 | 主珠编号 | 数量 | 环形位置 (array index) | 钟点方向 |
|------|---------|------|----------------------|----------|
| 第1段 | 1-27号 | 27颗 | 1-27 | 6 点 → 9 点（三通后第一段） |
| 第2段 | 28-54号 | 27颗 | 29-55 | 9 点 → 12 点（腰珠后第二段） |
| 第3段 | 55-81号 | 27颗 | 57-83 | 12 点 → 3 点（顶珠后第三段） |
| 第4段 | 82-108号 | 27颗 | 85-111 | 3 点 → 6 点（腰珠后回到三通） |

**特殊珠子位置（钟点方向）：**

| 珠子类型 | array index | 钟点方向 | 角度 | 说明 |
|---------|-------------|----------|------|------|
| 三通 | 0 | **6 点钟** | π/2 | 环形底部，连接主珠 108 号和 1 号 |
| 腰珠1 | 28 | **9 点钟** | π | 在第1段和第2段之间 |
| 顶珠 | 56 | **12 点钟** | 3π/2 | 在第2段和第3段之间 |
| 腰珠2 | 84 | **3 点钟** | 0 | 在第3段和第4段之间 |

**约束要求：**

1. **分段完整性**：每段必须恰好27颗主珠，不能多也不能少
2. **编号连续性**：每段内的主珠编号必须连续，不能跳跃
3. **分段点固定**：27、54、81、108是分段点，对应每段最后一颗主珠的编号
4. **特殊珠子位置**：
   - 三通（index 0）在6点钟方向，连接首尾主珠
   - 腰珠1（index 28）在9点钟方向，第1段和第2段之间
   - 顶珠（index 56）在12点钟方向，第2段和第3段之间
   - 腰珠2（index 84）在3点钟方向，第3段和第4段之间
5. **修改约束**：
   - ❌ 禁止改变主珠总数（必须是108颗）
   - ❌ 禁止改变分段数量（必须是4段）
   - ❌ 禁止改变每段主珠数（必须是27颗）
   - ✅ 允许调整珠子位置（但必须保持分段结构）
   - ✅ 允许调整框架线形状（但必须保持分段结构）

**验证方法：**

```javascript
function validateSegmentation(mainBeads) {
  // 验证总数
  if (mainBeads.length !== 108) {
    throw new Error('主珠总数必须为108颗');
  }
  
  // 验证分段
  const segments = [
    mainBeads.slice(0, 27),   // 第1段：1-27号
    mainBeads.slice(27, 54),  // 第2段：28-54号
    mainBeads.slice(54, 81),  // 第3段：55-81号
    mainBeads.slice(81, 108), // 第4段：82-108号
  ];
  
  segments.forEach((segment, index) => {
    if (segment.length !== 27) {
      throw new Error(`第${index + 1}段必须为27颗主珠`);
    }
  });
  
  return true;
}
```

## 验证方法

每次修改珠子位置后，必须验证：

1. **框架线检查**：所有珠子必须在框架线上（根据框架线形状验证）
2. **重叠检查**：遍历所有珠子对，计算中心距，确保大于半径和
3. **视觉检查**：在浏览器中放大查看，确认无重叠
4. **框架线平滑检查**：如果使用非正圆框架线，确保曲线平滑无突变

## 计算公式

### 珠子中心距

```javascript
function distance(bead1, bead2) {
  return Math.sqrt(
    Math.pow(bead1.x - bead2.x, 2) + 
    Math.pow(bead1.y - bead2.y, 2)
  );
}
```

### 最小安全距离

```javascript
function minSafeDistance(bead1, bead2) {
  return (bead1.size + bead2.size) / 2;
}
```

### 重叠检测

```javascript
function isOverlapping(bead1, bead2) {
  return distance(bead1, bead2) < minSafeDistance(bead1, bead2);
}
```
