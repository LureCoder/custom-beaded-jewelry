# 空性念珠 · Kongxing Mala

## 品牌英文名

**Kongxing Mala**

| 中文 | 英文 | 说明 |
|------|------|------|
| 空性念珠 | Kongxing Mala | 官方品牌名 |
| 空性 | Kongxing / Śūnyatā | 哲学核心理念 — 万物皆空，不执不着 |
| 念珠 | Mala | 梵语 माला (mālā)，意为"花环"，西方通用的念珠称谓 |

> **Kongxing** 是 空性 (śūnyatā) 的音译，既保留了东方哲学的韵尾，又易于英文使用者发音。**Mala** 是梵语中念珠的原名，比 "Prayer Beads" 更精确、更文化本真。

## 品牌定位

### 核心理念

**不为物役，不以物喜。**

空性念珠不是装饰品，不是时尚配饰。它是修行的工具，是每日觉知的提醒，是一颗颗珠子串起的冥想之路。

### 目标用户

| 用户画像 | 特征 |
|----------|------|
| **修行者** | 每日持咒/冥想，需要高品质法器的佛弟子 |
| **觉知生活者** | 不特定宗教信仰，但追求正念（Mindfulness）生活的现代人 |
| **文化审美者** | 被东方哲学与手工艺美学吸引，寻求精神归属感 |
| **送礼者** | 为亲友选购有深意的礼物，看重寓意而非价格 |

### 品牌调性关键词

```
空 · 静 · 质 · 慢 · 真
```

| 维度 | 表现 |
|------|------|
| **空** | 不堆砌，不繁复，每件产品都有留白 |
| **静** | 产品呈现宁静感，不张扬，不喧哗 |
| **质** | 材质为本，工匠精神，每一颗珠都经得起凝视 |
| **慢** | 手工制作需要时间，我们不急于出货，用户也不急于拥有 |
| **真** | 真实材质，真实产地，真实工艺，没有虚假的故事 |

## 产品详情页设计规范

### 内容结构

```
1. 产品名称（H1）
   └─ 简短副标题（材质 / 珠数 / 一句话）

2. 产品图片（第一屏）
   └─ 深色背景 / 侧光 / 45度俯拍
   └─ 必选：整体图 / 细节微距 / 手持图

3. 材质信息
   └─ 材质名称 + 产地 + 选材标准
   └─ 配件材质说明

4. 工艺说明
   └─ 匠人姓名（如有）+ 工艺耗时
   └─ 打磨目数 + 品质等级

5. 尺寸规格
   └─ 主珠直径 / 珠数 / 总长 / 重量

   └─ 手工制作，下单后 [X] 天发货
   └─ 每件附赠：收纳袋 + 保养卡

8. 品牌寄语
   └─ 固定文案（见下方）
```

## 产品摄影风格

### 核心原则

- **深色背景**：纯黑或深灰背景，突出珠体质感
- **侧光照明**：单一侧光源，制造阴影层次
- **45度俯拍**：展示念珠整体形态
- **微距特写**：至少一张，展示木材纹理 / 水晶冰裂 / 菩提眼正

### 必拍角度

| 角度 | 用途 | 说明 |
|------|------|------|
| 俯拍全貌 | 主图 | 45度俯拍，展示完整的108珠排列 |
| 侧面 | 副图 | 展示珠串厚度与佛头侧面 |
| 微距 | 细节图 | 展示材质纹理（3-5倍放大） |
| 手持 | 场景图 | 自然光下，人手盘握的画面 |
| 静物 | 氛围图 | 念珠置于经文/莲花/木质佛台上 |

### 后期调色

| 参数 | 方向 |
|------|------|
| 色温 | +5 （偏暖） |
| 对比度 | +10 （增强质感） |
| 清晰度 | +15 （突出纹理） |
| 饱和度 | -5 （沉稳） |
| 暗角 | 轻微 （聚焦中心） |

## 定价策略

### 定价公式

```
零售价 = (材料成本 + 工时费) × 品牌系数
```

| 系列 | 品牌系数 | 说明 |
|------|----------|------|
| 菩提系列 | 2.5 - 3.0 | 入门走量，适中溢价 |
| 木料系列 | 3.0 - 4.0 | 材质贵重，更高溢价 |
| 水晶系列 | 2.5 - 3.5 | 通透精美，中高溢价 |
| 玛瑙系列 | 2.0 - 2.5 | 材料成本低，亲民定价 |

### 定价对照

| 层级 | 代表产品 | 价格带 | 目标 |
|------|----------|--------|------|
| 入门 | 星月菩提 108 | ¥298 - ¥398 | 降低首次购买门槛 |
| 主力 | 凤眼菩提 108 | ¥398 - ¥598 | 核心利润产品 |
| 进阶 | 小叶紫檀 108 | ¥898 - ¥1,980 | 品质升级选择 |
| 收藏 | 沉香 108 | ¥1,980 - ¥2,980 | 品牌高度象征 |

- 所有价格以 8 结尾（东方文化吉祥数字）
- 不设"折扣价/原价"对比（禅意品牌不搞促销感）
- 不设"满减"或"凑单"（破坏品牌调性）

## 产品描述文案规范

### 标题格式

```
[材质] [工艺] 108 念珠
```

### 正文风格

| 原则 | 说明 |
|------|------|
| 客观 | 描述材质产地、工艺标准，不使用夸张修辞 |
| 简洁 | 每段不超过 3 句话 |
| 克制 | 不写长篇品牌故事，让产品本身说话 |
| 知识性 | 提供有价值的鉴别/保养知识 |

### 禁用词汇

```
❌ 精品     ❌ 至尊     ❌ 极品     ❌ 限量
❌ 独家     ❌ 首发     ❌ 抢购     ❌ 爆款
❌ 秒杀     ❌ 超值     ❌ 跳楼价   ❌ 最后一天
```

### 推荐用词

```
✅ 手工制作  ✅ 天然材质  ✅ 匠人打磨  ✅ 经典
✅ 精选     ✅ 手工      ✅ 自然      ✅ 素雅
```
